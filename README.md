# Software Development & Code Examples

This repository features demo implementations of software design patterns and high-performance computing (HPC) techniques.

## DesignPattern
A standalone C++ demonstration of the Composite Design Pattern, showcasing clean object-oriented architecture and automated testing.
•	Key Features: Full implementation of the Composite pattern, complete with an accompanying UML structural diagram.
•	Testing Framework: Integrated with Catch2 for robust unit testing and verification.
•	How to Run:
1.	Open the solution file (.sln) in Visual Studio.
2.	Build the project in your preferred configuration.
3.	Execute the binary to run the Catch2 test suite and verify that all assertions pass successfully.


## High-Performance Computing (HPC)
A performance-critical code examples for parallel computing and hardware acceleration.
GPU Optimization (CUDA)
An optimized implementation of General Matrix Multiplication (GEMM) using NVIDIA CUDA and C++.
•	Optimization Technique: Implements Shared Memory Tiling to maximize memory bandwidth, minimize global memory latency, and dramatically improve compute throughput.
•	Tech Stack: C++, CUDA C.
